# C Programming Practice

A structured collection of beginner-friendly C programs, examples, and exercises developed while learning the fundamentals of **C programming**.

The repository is organized by topic to make examples easier to find, review, compile, and practice.

## Repository Structure

| Directory | Topics |
|---|---|
| `01-introduction/` | C fundamentals, program structure, comments, and output |
| `02-variables-and-data-types/` | Variables, constants, data types, and memory size |
| `03-operators/` | Arithmetic, assignment, comparison, and logical operators |
| `04-control-flow/` | Conditional statements and switch-case |
| `05-loops/` | Looping concepts and iteration |
| `06-examples/` | Additional beginner examples |
| `07-array/` | Arrays, multidimensional arrays, and array traversal |
| `08-strings/` | Strings and string-related operations |
| `09-input_output/` | Reading user input and displaying output |
| `10-memory/` | Pointers, pointer arithmetic, and memory concepts |
| `11-function/` | Functions, parameters, and return types |
| `w3school/` | Practice files based on W3Schools C tutorials |
| `project/` | Small practical C projects |

## Getting Started

### Requirements

- A C compiler (GCC recommended)
- A terminal or code editor, such as Visual Studio Code

### Compile and Run

With GCC installed, open a terminal in the repository and run:

```bash
gcc path/to/program.c -o program
./program
```

On Windows PowerShell:

```powershell
gcc path/to/program.c -o program.exe
.\program.exe
```

Replace `path/to/program.c` with the path to the source file you want to run.

## Learning Goals

- Understand C syntax and program structure.
- Practice variables, data types, operators, and control flow.
- Work with loops, arrays, strings, and functions.
- Build a foundation in pointers and memory management.
- Strengthen problem-solving through small programs and projects.
