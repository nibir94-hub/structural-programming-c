# Structural Programming in C

Beginner-friendly C examples covering the fundamentals of structural programming.

## Topics

The current examples are grouped conceptually as follows:

- **Basics:** `Cintro.c`, `comments.c`, `printf.c`, `numbers.c`, `NEWLINES.C`
- **Data types:** `datatypes.c`, `char.c`, `Cconstants.c`, `DecimalPrecision.c`, `MemorySize.c`, `FORMATSPECIFIERS.C`
- **Operators:** `ArithmeticOperators.c`, `AssignmentOperators.c`, `ComparisonOperators.c`, `LogicalOperator.c`, `operators.c`
- **Conditionals:** `ifelse.c`, `else.c`, `elseif.c`, `switch.c`
- **Loops:** `loop.c`
- **Variables:** `createvariables.c`, `variablenames.c`, `changevalues1.c`, `changevalues2.c`, `changevalues3.c`, `changevalues4.c`, `multiplevariable.c`, `multipletevariables2.c`
- **Examples:** `anotherexample.c`, `reallifedatatypesexample.c`, `reallifeexampleofvariables.c`, `reallife`

## Compiling an example

Using GCC:

```bash
gcc printf.c -o build/printf
./build/printf
```

On Windows, run the generated executable with:

```powershell
.\build\printf.exe
```

## Repository conventions

- Keep source files focused on one concept.
- Use lowercase, descriptive filenames for new examples.
- Do not commit compiled executables or object files.
- Use clear commit messages such as `Add examples for C data types`.
