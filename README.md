# structural-programming-c

This repository is organized by topic while keeping the README at the top level.

The original files in the root folder are left in place for now, and the organized copies are stored in topic-based folders.

## Folder structure

- `01-introduction/` - basic C programs and intro examples
- `02-variables-and-data-types/` - variables, constants, data types, and value changes
- `03-operators/` - arithmetic, assignment, comparison, and logical operators
- `04-control-flow/` - if/else, switch, and decision-making examples
- `05-loops/` - while, do-while, for, and nested loops
- `06-examples/` - additional practical examples
